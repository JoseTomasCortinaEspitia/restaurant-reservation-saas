# Restaurant Reservation SaaS

A full-stack, multi-tenant restaurant reservation management platform.

## Tech Stack

- Next.js
- TypeScript
- Node.js
- Express
- PostgreSQL
- Prisma ORM
- Docker
- Tailwind CSS

## Features (planned)

- Multi-restaurant management
- Authentication and role-based access
- Restaurant booking system
- Availability management
- Reservation dashboard
- Daily reports
- Simulated notifications

## Development

### Database

docker compose up -d

### Backend

cd server
npm install
npx prisma migrate dev
npm run dev

### Frontend

cd client
npm install
npm run dev
